# Virtual AI Keyboard

A touchless virtual keyboard built using Python and computer vision.

## Overview

This project uses a webcam to track hand movements
and interact with a virtual keyboard.

## Technologies

- Python
- OpenCV
- CVZone
- MediaPipe
- NumPy
- Pynput

## Planned Features

- [ ] Webcam integration
- [ ] Hand detection
- [ ] Finger tracking
- [ ] Virtual keyboard interface
- [ ] Gesture-based typing
